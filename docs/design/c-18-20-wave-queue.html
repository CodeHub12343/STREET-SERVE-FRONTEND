Journey shape

  • C-18 → C-19 → C-20 is one commitment escalator: confirm costs nothing, waiting is cancellable, and the queue is the only state with something to lose (your locked tier) — so the leave action gets progressively quieter (ghost-danger text, never a red button).
  • Every screen answers the same three questions: where's the vendor, what do I get, what can I do right now.

SLA & trust language (FR-2.2)

  • The 5-minute response promise is stated before sending, counted down during (tabular numerals, no anxiety-red until expiry), and honored after — decline and expiry both say "nothing was charged."
  • Failure states always come with a next move: the closest alternative vendor, one tap to re-wave (Flow 2 error state).

Discount locking (FR-3.3)

  • "15% locked in" appears at acceptance and never changes — the violet discount chip is the through-line across accepted → queue → your-turn.
  • The queue screen restates it as "locked at join" so cancellations ahead never make the user doubt their tier.

Queue mechanics

  • Position rendered giant + dot rail: served dots fade, your dot is the violet one — glanceable from arm's length outdoors.
  • Pop-Up delay arrives as a §2.6d warning banner (simulate it above): explains the delay AND reassures spot + discount are safe in the same breath (FR-4.1).
  • Hold-my-spot (15 min geofence grace, FR-3.4) stated passively — no action needed to keep it.

Handoff notes

  • Countdown, ETA and positions all from server events (`/queue/:id` socket) — client never computes position locally (FR-3.2).
  • Accepted-state route line is decorative dashed accent; real routing ETA comes from the vendor's nav, not client-side estimation.
  • "You're up" fires a push + haptic; discount applies server-side at transaction (C-22), never as a code the user must show.
