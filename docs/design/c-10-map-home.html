Anatomy · MapShell

  • Search + tab header — pinned over map with a surface fade; tabs per client mockup (All/Food/Coffee/Services/Shopping/More). "More" opens the full category browser (C-13).
  • Pins — business's own logo (emoji stand-ins here) in a 48px circle with a 3px status ring; travel-time chip below in tabular numerals.
  • Serve Near Me — floating primary map action; recenters + refreshes. High-contrast neutral, so orange stays reserved for Wave Down.
  • Sheet peek — first snap point of C-14 (§2.6f): identity, status chip, rating, ETA, primary action. Pull up → half/full profile.
  • Tab bar — Map · Favorites · Orders · Messages · Profile, active in accent-secondary.

Status model (§2.2 tokens)

  • Driving — green ring + pulse (Taco Loco roams to show live movement).
  • Parked — blue ring, stationary, all actions available.
  • Away/Closed — violet ring, desaturated face, "Closed" chip; Wave Down swaps to Notify Me in the sheet (tap Sweet Treats 🧁).

States shown

  • Loading — skeleton circles at pin geometry (§2.6e), never a spinner.
  • Empty — actionable card per the "empty state as a sales tool" rule: widen radius / see scheduled.
  • Toast — §2.6d transient feedback, fired by Serve Near Me and the "More" tab.

Spec & handoff notes

  • Type is specified as Inter/Inter Tight; this mockup renders the system stack as a stand-in (font CDNs are blocked in artifacts).
  • Pins never overlap the FAB zone; at density they cluster (cluster pin variant, designed with C-17).
  • Reduced motion: pulse, roam and shimmer collapse to static.
  • Full interaction spec: docs/13-screen-design-specs.md § C-10.
